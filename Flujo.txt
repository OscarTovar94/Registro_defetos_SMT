Flujo propuesto:

1- Selecciona el modelo.

2- Se muestra:
	- número de parte
	- renglones
	- columnas
	- total de posiciones:
		PCB1	PCB2	PCB3	PCB4
		PCB5	PCB6	PCB7	PCB8
		PCB9	PCB10	PCB11	PCB12
			
3- Se dibuja la cuadrícula completa del panel.

4- El operador selecciona solo las posiciones que tienen defecto.

5- Para cada posición seleccionada captura el ID de 16 dígitos.

6- El sistema valida:
		- que tenga 16 dígitos
		- que sea numérico
		- que los primeros 6 dígitos coincidan con el número de parte
		- que no esté repetido

7- Al confirmar el panel:
		- las posiciones seleccionadas pasan a ser PCB defectuosas pendientes de clasificar
		- todas las posiciones no seleccionadas se consideran PASS automáticamente

8- Se cierra la cuadrícula inicial.

9- Se muestra solamente una lista con las PCB defectuosas:
		- posición
		- ID
		- estado pendiente

10- El operador registra uno o varios defectos para cada PCB.

11- Al terminar todas las PCB defectuosas se muestra el resumen.

12- Se finaliza el panel y se actualiza el dashboard por modelo.
